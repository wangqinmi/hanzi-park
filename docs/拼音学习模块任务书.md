# 📖 汉字乐园 · 汉语拼音学习模块 任务书

> 版本：v1.0 ｜ 日期：2026-08-29 ｜ 状态：待评审

## 1. 项目目标

在现有「汉字乐园 · 幼儿识字120」应用内，新增一个完整的**汉语拼音学习模块**，面向 3–8 岁幼儿与小学低年级学生，与现有识字模块形成「拼音 → 汉字」的学习闭环：

- 认读：23 个声母、24 个韵母、16 个整体认读音节、4 种声调；
- 拼读：两拼音节、三拼音节及核心拼读规则；
- 书写：四线三格内的拼音字母描红；
- 巩固：拼音小游戏与成就徽章；
- 联动：汉字卡上的拼音可一键跳转到对应拼音学习页。

## 2. 用户与场景

| 用户 | 场景 |
|---|---|
| 幼儿/小学生 | 在家长陪同下，每天 10–15 分钟学习 1–2 个拼音、玩 1 局拼音游戏 |
| 家长 | 查看孩子学习进度、陪同跟读 |
| 幼小衔接教师 | 课堂演示声母韵母、声调 |

## 3. 功能需求（按优先级）

### P0（核心，必须）
1. **拼音总览**：声母表 / 韵母表（单韵母·复韵母·前鼻·后鼻）/ 整体认读音节表，分类页签 + 卡片网格；
2. **单个拼音学习页**：大字拼音 + 四声调标注 + 🔊 发音朗读 + 记忆口诀 + 图片联想 + 例字（带跳转到汉字卡）；
3. **声调学习**：ā á ǎ à 四声演示（发音 + 手势动画 + 例字），轻声说明；
4. **拼读练习**：声母+韵母两拼/三拼组合拼读（点声母、点韵母、听合成读音），j q x y 与 ü 相拼去两点等规则的趣味提示；
5. **与汉字模块联动**：120 个字卡的拼音均可点击跳转到拼音模块对应页面（数据已具备，零成本）。

### P1（重要，第二期）
6. **拼音书写**：四线三格画布 + 字母描红（复用现有书写引擎的演示/描红判分/自由画三种模式）；
7. **拼音游戏**：
   - 「找声母」：听发音选声母；
   - 「拼一拼」：点选声母+韵母组成听到的音节；
   - 「声调小火车」：给音节选对声调。

### P2（可选，增强）
8. 跟读评分（麦克风录音+波形反馈，仅提示"再大声一点"，不做精确评分）；
9. 拼音字母歌 / 顺口溜合集；
10. 字卡详情页展示"这个字的拼音怎么拼"拆解（声母+韵母+声调）。

## 4. 内容与数据清单

### 4.1 拼音总表（63 项）

**声母 23 个**：b p m f ｜ d t n l ｜ g k h ｜ j q x ｜ zh ch sh r ｜ z c s ｜ y w

**韵母 24 个**：
- 单韵母 6：a o e i u ü
- 复韵母 9：ai ei ui ao ou iu ie üe er
- 前鼻韵母 5：an en in un ün
- 后鼻韵母 4：ang eng ing ong

**整体认读音节 16 个**：zhi chi shi ri zi ci si yi wu yu ye yue yuan yin yun ying

**声调**：一声ˉ / 二声ˊ / 三声ˇ / 四声ˋ / 轻声

### 4.2 每条拼音需准备的数据（数据结构草案）

\`\`\`json
{
  "b": {
    "cat": "声母",
    "read": "bō",
    "tip": "像个广播，右下半圆 b b b",
    "img": "img/pinyin/b.svg",
    "examples": ["爸", "八"],
    "spell": ["b", "a"]
  }
}
\`\`\`

说明：`read` 用带声调韵母的标准读法，保证 TTS 发音准确（如 b→读"bō"）。

### 4.3 拼读规则清单（需趣味化呈现）

| 规则 | 示例 |
|---|---|
| 两拼音节：声母+韵母 | b-a → ba，m-a → ma |
| 三拼音节：声母+介母(i/u/ü)+韵母 | g-u-a → gua |
| j q x 见到 ü，两点去掉 | j-ü → ju |
| y 与 ü 相拼去两点 | y-ü → yu |
| 标调规则：有 a 标 a，没 a 找 o e，i u 并列标在后 | māo、duì |
| 轻声：不标调 | 爸爸 bà ba |

## 5. 技术方案与复用分析

### 5.1 可直接复用的资产（零/低成本）

| 现有资产 | 复用到拼音模块 |
|---|---|
| 卡通 UI 体系（配色/卡片/弹层/吉祥物/飘云） | 拼音总览、学习页、游戏界面直接套用 |
| 书写引擎（演示动画/描红判分/自由画） | 改造为四线三格画布，供字母描红使用 |
| 语音体系（Edge 神经网络语音 + 缓存预合成 + 系统语音回退） | 拼音发音、拼读朗读直接调用；需适配单字母读法 |
| 成就/存档/星星体系 | 新增拼音徽章与学习记录字段 |
| 游戏框架（配对/翻翻乐/找朋友玩法） | 「找声母」「拼一拼」可复用配对与四选一逻辑 |
| QA 自动化测试 + APK 打包流水线 | 拼音模块测试与发布零新增成本 |
| 120 字库中的拼音字段 | 汉字→拼音双向跳转 |

### 5.2 需新增开发的内容

1. `js/pinyin-data.js`：63 项拼音数据（口诀/例字/图片/拼读组合）；
2. 拼音总览页、单拼音学习页、声调页、拼读页（HTML/CSS/JS）；
3. 四线三格画布（横线背景 + 字母描红路径数据，约 26 个小写字母 + ü 的简笔路径，手绘 SVG）；
4. TTS 拼音读法适配（单字母用带调韵母读法，如 b→读"bō"；音节直接读带调音节）；
5. 3 个拼音小游戏；
6. 成就徽章（拼音小达人等）+ 学习记录。

### 5.3 风险点与对策

| 风险 | 对策 |
|---|---|
| TTS 读单个声母不准（b 读成"逼"） | 统一用「带声调韵母」读法（b→"bō"），并附例字朗读 |
| 字母笔顺没有现成权威数据 | 手绘简化描红路径（字母笔画简单，26+1 个，工作量可控） |
| 图片联想素材 | 优先复用 Twemoji/自制简笔 SVG，规避版权问题 |
| ü 去点、轻声等规则的讲解 | 用口诀+动画（ü 摘墨镜等趣味表达），配例字 |
| 若后续转小程序：教育类目资质 | 本次先在网页版+APK 落地，小程序另立项评估 |

## 8. 验收标准（摘要）

1. 63 项拼音全部发音正确（抽样 20 项人工听验）；
2. 声调、轻声、ü 去点、标调规则展示无误；
3. 四线三格描红三种模式可用，判分与现有汉字描红一致；
4. 3 个游戏各完整通关一次，无卡死；
5. 120 个字卡拼音跳转全部有效（自动化校验）；
6. 网页版 QA 脚本全绿；APK 正常打包安装；语音在联网/离线两种状态下均可发声。
