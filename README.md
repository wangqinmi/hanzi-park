# 🐼 汉字乐园 · 幼儿识字 120

一个完全离线可用的幼儿识字网页应用：**120 个最简单最常用的汉字**，卡通界面 + 图片联想 + 两种趣味学习法，覆盖「学读、学写、懂意思」。

🔗 **GitHub 仓库**：https://github.com/wangqinmi/hanzi-park （欢迎 Star ⭐）

> 当前版本：**v1.0** · 双图识字 · 神经网络语音 · 笔顺演示/描红/自由画

## 🚀 怎么使用

### 📱 Android 手机/平板（推荐）

安装根目录的 **`汉字乐园.apk`**（约 1.3MB，Android 5.0 及以上）：

1. 把 APK 文件传到手机上（微信、QQ、数据线均可）；
2. 点击安装；若提示"未知来源应用"，按提示在系统设置里允许"安装未知应用"；
3. 打开「汉字乐园」即可使用——已内置中文语音（学读/跟读直接调用系统 TTS），**完全离线**。

> APK 使用开发调试证书签名（个人使用足够）。应用图标为熊猫+「字」徽章。

**🔊 语音说明**：点按汉字/词语/句子/解释/口诀都会朗读。APK 内置**微软 Edge 神经网络语音**（真人级音色，联网时优先使用），并带**语音缓存＋打开字卡自动预合成**，重复点按和常用内容秒读无延迟；网络不可用时自动回退到手机系统中文语音。电脑网页版会自动选择系统里最自然的中文音色（如 Windows 上 Edge 的 "Xiaoxiao Natural" 等在线自然语音）。

### 💻 电脑浏览器

直接双击打开 `index.html` 即可（Chrome / Edge / Safari 均可，推荐 Chrome）。

> 如果浏览器限制了本地文件，可在本目录运行：`python3 -m http.server 8000`，然后访问 http://localhost:8000

**建议**：iPad 或大屏手机上横屏使用，体验最佳。学习进度自动保存在本地。

## 🎯 120 个字的选取依据

- **100 个**：人教版小学语文一年级上册《会写字》表（官方要求一年级上学期会写的全部生字）；
- **20 个**：幼儿生活高频字（爸、妈、家、爱、好、玩、看、听、说、读、写、笑、吃、喝、学、习、猫、狗、花、草）。

按主题分为 12 类：数字王国、大自然、动物朋友、我的身体、我爱我家、学习乐园、动作真有趣、方位与形状、日常生活、时间与状态、好宝宝、常用字。

## 🎓 识字学堂（学读 · 学写 · 懂意思）

点开任意字卡：

| 功能 | 说明 |
|---|---|
| 🔊 听一听 | 系统中文语音朗读「字 → 组词 → 句子」，可反复跟读 |
| ✍️ 学写字 | **看演示**：按笔顺逐笔显现的**硬笔书写动画**（实心笔画＋笔尖圆点）；**描一描**：跟着浅橙色实心笔画描红（传统描红本样式），智能判分（距离＋覆盖率双校验，描对变粉红、描错有鼓励＋自动演示提示、可跳过）；**自由画**：照着灰影子自由画，一键清空 |
| 💡 字的意思 | 完整儿童化释义（点按钮或点释义文字都会朗读）+ 可点读的组词/例句/记忆口诀 |
| 🖼️ 双图识字 | 每个字配两张风格不同的清晰图片：系统表情图 + Twemoji 矢量插画图（并排展示）；看图认字、找朋友游戏会随机轮换两种图片 |
| ✨ 图画变汉字 | 40 个字有「图片 → 象形画 → 汉字」三格演变，点一点听讲解 |

笔画数据来自开源项目 [hanzi-writer-data](https://github.com/chanind/hanzi-writer-data)（npm 最新版 2.0.1，源自 Make Me a Hanzi 项目），与小学语文一年级上册《会写字》笔顺一致，已本地化打包、完全离线可用；书写引擎（笔顺演示 / 描红判分 / 自由画）为本应用自研实现，支持手指、触控笔和鼠标。插画图使用 [Twemoji](https://github.com/jdecked/twemoji) 矢量图形（CC-BY 4.0，© Twitter/X），已本地化打包。

## 🔤 拼音乐园（M1 已上线）

首页新增「拼音乐园」入口，覆盖汉语拼音三大类：

| 分类 | 数量 | 学习内容 |
|---|---|---|
| 声母 | 23 个 | 呼读音（bō pō mō fō…）、口诀、图片、例字 |
| 韵母 | 24 个 | 单韵母/复韵母/前鼻/后鼻分组，**四声调逐一点读** |
| 整体认读 | 16 个 | zhi chi shi ri…带声调点读 |

- **双向联动**：120 个字卡的拼音可点击跳转到对应拼音页；拼音例字（如"妈、马"）可跳回汉字卡；
- **读音准确性三重保障**：① 63 项读音与权威呼读音表逐项对照校验；② 声调例字自洽校验（含 ü 去点、iu/un 缩写标调等标准写法）；③ 音频全部由神经网络语音朗读标准例字（纯汉字），发音准确可复听。

## ✍️ 拼音书写与游戏（M3 已上线）

- **四线三格学写字母**：拼音详情页新增「学写字母」——红蓝四线三格画布 + 26 个字母描红路径，看演示（按笔顺动画）/ 描一描（智能判分）/ 自由画三种模式；
- **拼音游戏 ×3**：「找声母」（听词选声母）、「拼一拼」（听词拼音节）、「声调小火车」（听词选声调车厢），每局闯关奖励星星；
- **拼音徽章**：新增「声调小耳朵」「拼音小达人」两枚成就徽章（累计答对/拼对解锁）。

## 🖼️ 双图识字

每个字都配了**两张风格不同的清晰图片**，帮助小朋友多角度建立「字—形—义」的联系：

| | 表情图 | 插画图 |
|---|---|---|
| 来源 | 系统原生表情（3D 质感） | Twemoji 矢量插画（扁平风格） |
| 格式 | 系统字体渲染 | SVG 矢量，任意尺寸清晰 |
| 展示 | 详情页左框（黄底） | 详情页右框（蓝底），并排摆放 |
| 游戏 | 看图认字、找朋友随机轮换两种图片 | 同左 |

> 两张图都经过逐字检查、全部本地化打包，离线可用。

## 🖼️ 趣味方法① 图画变变变

- **看图认字**：看大图片，四选一找对应的汉字；
- **象形变变变**：40 个象形字（日月山水火木田雨…）的图画演变展，每格可点、可听。

## 🎮 趣味方法② 闯关大冒险

- **连连看**：图片和汉字配对；
- **翻翻乐**：翻牌记忆配对；
- **找朋友**：听读音看汉字，找对应的图片。

答对得分、连闯 10 题奖励星星，还有五彩纸屑和欢呼音效。

## 🏆 成就系统

学会的字自动点亮，按进度解锁 6 枚徽章：初识汉字 → 小小书虫 → 破茧成蝶 → 识字小达人 → 汉字小明星 → 汉字小博士。进度保存在浏览器 localStorage，可一键重置。

## 🎨 关于卡通伙伴

由于迪士尼、哆啦A梦等经典动画 IP 受版权保护，本应用使用了 **4 个原创卡通伙伴**（乐乐猫、贝贝熊、图图兔、阿鸭）——它们采用经典卡通的大眼睛、圆脑袋画风，负责欢迎、鼓励和表扬小朋友。

## 📦 重新打包 APK

```bash
# 环境要求：JDK 17、Android SDK（platforms;android-34 + build-tools;34.0.0）、Gradle 8.7
cd android/
echo "sdk.dir=/你的AndroidSDK路径" > local.properties
gradle assembleRelease   # 或 ./gradlew assembleRelease
# 产物：app/build/outputs/apk/release/app-release.apk
```

> 依赖仓库已配置**阿里云 Maven 镜像**（国内下载 AGP/OkHttp 更快更稳），也可自行改回 google()。
